### 1. Core Backtesting Engine (`backtesting/engine.py`)

#### Classes Required:

**`Backtester`** - Main orchestrator class

**Constructor Parameters:**
- `strategy_fn: Callable` - Function that generates portfolio weights given data
- `start_date: str` - Backtest start (format: "YYYY-MM-DD")
- `end_date: str` - Backtest end
- `initial_capital: float` - Starting capital (default: 25000)
- `rebalance_frequency: str` - "monthly", "quarterly", "weekly", "daily"
- `transaction_cost: float` - Basis points per trade (default: 10 bps = 0.001)
- `slippage_model: str` - "fixed", "volume_based", "spread_based" (default: "fixed")
- `fixed_slippage_bps: float` - Fixed slippage in bps (default: 5 bps)
- `market_impact_model: str` - "none", "sqrt", "linear" (default: "sqrt")
- `lookback_window: int` - Days of history for strategy (default: 252)
- `min_price: float` - Filter stocks below this price (default: 5.0)
- `max_position_size: float` - Max weight per position (default: 0.15 = 15%)
- `max_sector_concentration: float` - Max weight per sector (default: 0.30 = 30%)
- `min_trade_size: float` - Min trade size to execute (default: 100 USD)
- `short_selling: bool` - Allow shorts (default: False)
- `leverage: float` - Max leverage (default: 1.0 = no leverage)
- `benchmark_ticker: str` - Benchmark for comparison (default: "SPY")
- `risk_free_rate: float` - Annual risk-free rate (default: 0.04 = 4%)
- `verbose: bool` - Print progress (default: True)

### 4. Comprehensive Testing (`test_backtester.py`)

```python
import unittest
from backtesting.engine import Backtester, BacktestResult
from backtesting.strategies import magic_formula_strategy

class TestBacktester(unittest.TestCase):

    def test_simple_backtest(self):
        """Test basic backtest runs without errors."""
        bt = Backtester(
            strategy_fn=magic_formula_strategy,
            start_date="2020-01-01",
            end_date="2021-12-31",
            initial_capital=100000,
            rebalance_frequency="monthly",
            verbose=False
        )
        result = bt.run()

        # Assertions
        self.assertIsInstance(result, BacktestResult)
        self.assertGreater(result.total_return, -0.5)  # Not catastrophic loss
        self.assertLess(result.max_drawdown, 0)  # Drawdown is negative
        self.assertEqual(result.rebalance_count, 24)  # 24 months

    def test_transaction_costs_reduce_returns(self):
        """Verify costs are applied correctly."""
        # Run with 0 cost
        bt_no_cost = Backtester(
            strategy_fn=magic_formula_strategy,
            start_date="2020-01-01",
            end_date="2021-12-31",
            transaction_cost=0,
            fixed_slippage_bps=0
        )
        result_no_cost = bt_no_cost.run()

        # Run with realistic costs
        bt_with_cost = Backtester(
            strategy_fn=magic_formula_strategy,
            start_date="2020-01-01",
            end_date="2021-12-31",
            transaction_cost=10,
            fixed_slippage_bps=5
        )
        result_with_cost = bt_with_cost.run()

        # Costs should reduce returns
        self.assertLess(result_with_cost.total_return,
                       result_no_cost.total_return)

    def test_equity_curve_monotonic_time(self):
        """Equity curve should have no time gaps."""
        bt = Backtester(
            strategy_fn=magic_formula_strategy,
            start_date="2020-01-01",
            end_date="2020-12-31"
        )
        result = bt.run()

        dates = result.equity_curve['date'].values
        # Check dates are sorted and have no duplicates
        self.assertTrue(all(dates[i] < dates[i+1] for i in range(len(dates)-1)))

    def test_holdings_sum_to_portfolio_value(self):
        """Holdings + cash should equal total value."""
        bt = Backtester(
            strategy_fn=magic_formula_strategy,
            start_date="2020-01-01",
            end_date="2020-06-30"
        )
        result = bt.run()

        for _, row in result.equity_curve.iterrows():
            total = row['holdings_value'] + row['cash']
            self.assertAlmostEqual(total, row['portfolio_value'], places=2)

    def test_sharpe_ratio_calculation(self):
        """Verify Sharpe ratio is calculated correctly."""
        bt = Backtester(
            strategy_fn=magic_formula_strategy,
            start_date="2020-01-01",
            end_date="2021-12-31",
            risk_free_rate=0.02
        )
        result = bt.run()

        # Manual Sharpe calculation
        returns = result.equity_curve['portfolio_value'].pct_change().dropna()
        excess_returns = returns - (0.02 / 252)  # Daily RF rate
        expected_sharpe = (excess_returns.mean() / excess_returns.std()) * np.sqrt(252)

        self.assertAlmostEqual(result.sharpe_ratio, expected_sharpe, places=2)

    def test_max_drawdown_detection(self):
        """Verify max drawdown is detected correctly."""
        bt = Backtester(
            strategy_fn=magic_formula_strategy,
            start_date="2020-01-01",
            end_date="2021-12-31"
        )
        result = bt.run()

        # Manual drawdown calculation
        cummax = result.equity_curve['portfolio_value'].cummax()
        drawdowns = (result.equity_curve['portfolio_value'] - cummax) / cummax
        expected_max_dd = drawdowns.min()

        self.assertAlmostEqual(result.max_drawdown, expected_max_dd, places=4)

    def test_benchmark_comparison(self):
        """Test benchmark (SPY) is loaded and compared."""
        bt = Backtester(
            strategy_fn=magic_formula_strategy,
            start_date="2020-01-01",
            end_date="2021-12-31",
            benchmark_ticker="SPY"
        )
        result = bt.run()

        self.assertIsNotNone(result.benchmark_return)
        self.assertIsNotNone(result.alpha)
        self.assertIsNotNone(result.beta)
        self.assertGreater(result.benchmark_return, -0.5)  # SPY didn't collapse
```

### 6. Additional Requirements

**Data Handling:**
- Use existing `data/fetchers/yfinance_fetcher.py` for price/fundamental data
- Cache all data lookups to avoid repeated API calls
- Handle missing data gracefully (forward-fill prices, skip stocks with missing fundamentals)
- Handle corporate actions (splits, dividends) - adjust prices accordingly

**Rebalancing Logic:**
- On rebalance dates:
  1. Get filtered universe
  2. Calculate strategy weights
  3. Apply position/sector constraints
  4. Generate trades (delta between current and target)
  5. Execute trades with costs
  6. Update holdings
- Between rebalances: mark-to-market daily, no trades

**Performance Metrics:**
- Annualized return: `(final / initial)^(252 / days) - 1`
- Sharpe ratio: `(mean_return - rf) / std_return * sqrt(252)`
- Sortino ratio: Use downside deviation (only negative returns)
- Calmar ratio: `annualized_return / abs(max_drawdown)`
- Alpha/Beta: OLS regression vs benchmark
- Information ratio: `(portfolio_return - benchmark_return) / tracking_error`

**Visualization Requirements:**
- Use matplotlib + seaborn
- Professional styling (not default matplotlib colors!)
- Clear labels, titles, legends
- Grid lines for readability
- Log scale for equity curves
- Save as high-res PNG (300 DPI)

**Code Quality:**
- Type hints on all functions
- Comprehensive docstrings (Google style)
- Defensive programming (validate inputs)
- Logging (use Python logging module)
- No hardcoded paths (use pathlib)
- Configuration via dataclass or dict
