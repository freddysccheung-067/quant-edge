I have a quantitative trading system at `D:\quant-edge\` (GitHub: freddysccheung-067/quant-edge).

**Missing:**

3. Calculate running metrics (return, volatility, Sharpe, drawdown)

5. Generate automated reports

## Objective

Build a **production-grade performance tracking system** that:
- Survives restarts (persistent database)
- Tracks every trade with full attribution
- Calculates real-time risk metrics
- Generates daily/weekly reports automatically
- Alerts on threshold breaches (drawdown, vol spike)
- Enables deep post-mortem analysis (what worked, what didn't)

This is the "black box flight recorder" for the trading system.

### 1. Database Schema (`tracking/database/schema.sql`)

Use **SQLite** for simplicity (portable, no server required).

```sql
-- Trades table: Every execution
CREATE TABLE trades (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME NOT NULL,
    symbol TEXT NOT NULL,
    side TEXT NOT NULL,  -- 'buy' or 'sell'
    shares REAL NOT NULL,
    price REAL NOT NULL,
    notional REAL NOT NULL,  -- shares * price
    commission REAL DEFAULT 0,
    notes TEXT,
    signal_id INTEGER,  -- Link to signal that generated this trade
    FOREIGN KEY (signal_id) REFERENCES signals(id)
);

-- Signals table: Every signal generated (even if not executed)
CREATE TABLE signals (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME NOT NULL,
    strategy TEXT NOT NULL,  -- 'magic_formula', 'momentum', 'combined'
    symbol TEXT NOT NULL,
    action TEXT,  -- 'buy', 'sell', 'hold'
    target_weight REAL,
    score REAL,  -- Factor score/rank
    reason TEXT,  -- Why this signal was generated
    executed BOOLEAN DEFAULT 0  -- Was it actually traded?
);

-- Portfolio snapshots: Daily (or more frequent)
CREATE TABLE portfolio_snapshots (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME NOT NULL,
    total_value REAL NOT NULL,
    cash REAL NOT NULL,
    holdings_value REAL NOT NULL,
    total_return REAL,  -- Since inception
    daily_return REAL,
    benchmark_value REAL,  -- SPY benchmark tracking
    num_positions INTEGER,
    notes TEXT
);

-- Holdings: Current positions (updated on every trade)
CREATE TABLE holdings (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME NOT NULL,
    symbol TEXT NOT NULL,
    shares REAL NOT NULL,
    avg_cost REAL NOT NULL,  -- Average purchase price
    current_price REAL NOT NULL,
    market_value REAL NOT NULL,
    unrealized_pnl REAL,
    weight REAL,  -- % of portfolio
    UNIQUE(symbol, timestamp)
);

-- Performance metrics: Running calculations
CREATE TABLE performance_metrics (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME NOT NULL,
    metric_name TEXT NOT NULL,
    metric_value REAL NOT NULL,
    period TEXT,  -- 'daily', 'weekly', 'monthly', 'inception'
    notes TEXT
);

-- Alerts: Threshold breaches
CREATE TABLE alerts (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    timestamp DATETIME NOT NULL,
    alert_type TEXT NOT NULL,  -- 'drawdown', 'volatility', 'concentration'
    severity TEXT NOT NULL,  -- 'warning', 'critical'
    message TEXT NOT NULL,
    acknowledged BOOLEAN DEFAULT 0
);

CREATE INDEX idx_trades_timestamp ON trades(timestamp);
CREATE INDEX idx_trades_symbol ON trades(symbol);
CREATE INDEX idx_signals_timestamp ON signals(timestamp);
CREATE INDEX idx_portfolio_timestamp ON portfolio_snapshots(timestamp);
```

```python
    __tablename__ = 'trades'
```

### 3. Trade Logger (`tracking/logger/trade_logger.py`)

```python
from sqlalchemy.orm import Session
from tracking.database.models import Trade, Signal, Holding
from tracking.database.connection import get_db_session
from datetime import datetime
from typing import Dict, Optional

class TradeLogger:
    """
    Log executed trades and update holdings.

    Usage:
        logger = TradeLogger()
        logger.log_trade(
            symbol="AAPL",
            side="buy",
            shares=10,
            price=185.50,
            signal_id=123
        )
    """

    def __init__(self, db_path: str = "tracking/trading.db"):
        self.db_path = db_path

    def log_trade(self,
                  symbol: str,
                  side: str,
                  shares: float,
                  price: float,
                  commission: float = 0.0,
                  notes: str = None,
                  signal_id: Optional[int] = None) -> Trade:
        """
        Log a single trade execution.

        Returns the Trade object created.
        """
        with get_db_session(self.db_path) as session:
            trade = Trade(
                timestamp=datetime.now(),
                symbol=symbol,
                side=side,
                shares=shares,
                price=price,
                notional=shares * price,
                commission=commission,
                notes=notes,
                signal_id=signal_id
            )
            session.add(trade)
            session.commit()

            # Update holdings
            self._update_holdings(session, symbol, side, shares, price)

            return trade

    def _update_holdings(self,
                        session: Session,
                        symbol: str,
                        side: str,
                        shares: float,
                        price: float):
        """
        Update holdings after trade execution.

        Buy: Add to position (weighted average cost)
        Sell: Reduce position (FIFO assumed)
        """
        # Get current holding
        current = session.query(Holding).filter_by(symbol=symbol).order_by(Holding.timestamp.desc()).first()

        if side == 'buy':
            if current and current.shares > 0:
                # Average up
                total_cost = (current.shares * current.avg_cost) + (shares * price)
                new_shares = current.shares + shares
                new_avg_cost = total_cost / new_shares
            else:
                # New position
                new_shares = shares
                new_avg_cost = price

            holding = Holding(
                timestamp=datetime.now(),
                symbol=symbol,
                shares=new_shares,
                avg_cost=new_avg_cost,
                current_price=price,
                market_value=new_shares * price,
                unrealized_pnl=(price - new_avg_cost) * new_shares
            )
            session.add(holding)

        elif side == 'sell':
            if not current or current.shares < shares:
                raise ValueError(f"Cannot sell {shares} shares of {symbol}, only {current.shares if current else 0} held")

            new_shares = current.shares - shares
            if new_shares > 0:
                holding = Holding(
                    timestamp=datetime.now(),
                    symbol=symbol,
                    shares=new_shares,
                    avg_cost=current.avg_cost,  # Cost basis unchanged
                    current_price=price,
                    market_value=new_shares * price,
                    unrealized_pnl=(price - current.avg_cost) * new_shares
                )
                session.add(holding)
            # If new_shares == 0, position is closed (no holding entry needed)

    def get_recent_trades(self, limit: int = 50) -> List[Trade]:
        """Get most recent trades."""
        with get_db_session(self.db_path) as session:
            return session.query(Trade).order_by(Trade.timestamp.desc()).limit(limit).all()

    def get_trades_by_symbol(self, symbol: str) -> List[Trade]:
        """Get all trades for a symbol."""
        with get_db_session(self.db_path) as session:
            return session.query(Trade).filter_by(symbol=symbol).order_by(Trade.timestamp).all()
```

```python
class PortfolioLogger:
    """
    Take daily snapshots of portfolio state.

    Run this every day after market close (or more frequently).
    """

    def __init__(self, db_path: str = "tracking/trading.db"):
        self.db_path = db_path

    def log_snapshot(self,
                    total_value: float,
                    cash: float,
                    holdings_value: float,
                    benchmark_value: float = None,
                    notes: str = None) -> PortfolioSnapshot:
        """
        Log a portfolio snapshot.

        Args:
            total_value: Total portfolio value (cash + holdings)
            cash: Cash balance
            holdings_value: Market value of all holdings
            benchmark_value: SPY benchmark value for comparison
        """
        with get_db_session(self.db_path) as session:
            # Get previous snapshot for returns calculation
            prev = session.query(PortfolioSnapshot).order_by(PortfolioSnapshot.timestamp.desc()).first()

            if prev:
                daily_return = (total_value - prev.total_value) / prev.total_value
                total_return = (total_value - 25000) / 25000  # Assuming $25k initial
            else:
                daily_return = 0.0
                total_return = 0.0

            # Count positions
            holdings = session.query(Holding).filter(Holding.shares > 0).all()
            num_positions = len(holdings)

            snapshot = PortfolioSnapshot(
                timestamp=datetime.now(),
                total_value=total_value,
                cash=cash,
                holdings_value=holdings_value,
                total_return=total_return,
                daily_return=daily_return,
                benchmark_value=benchmark_value,
                num_positions=num_positions,
                notes=notes
            )
            session.add(snapshot)
            session.commit()

            return snapshot

    def get_equity_curve(self) -> pd.DataFrame:
        """
        Get full equity curve as DataFrame.

        Returns:
            DataFrame with columns: timestamp, total_value, benchmark_value, total_return
        """
        with get_db_session(self.db_path) as session:
            snapshots = session.query(PortfolioSnapshot).order_by(PortfolioSnapshot.timestamp).all()

            return pd.DataFrame([{
                'timestamp': s.timestamp,
                'total_value': s.total_value,
                'benchmark_value': s.benchmark_value,
                'total_return': s.total_return,
                'daily_return': s.daily_return,
                'num_positions': s.num_positions
            } for s in snapshots])
```

### 5. Metrics Calculator (`tracking/metrics/calculator.py`)

```python
class MetricsCalculator:
    """
    Calculate all performance metrics from portfolio history.
    """

    def __init__(self, db_path: str = "tracking/trading.db"):
        self.db_path = db_path

    def calculate_all_metrics(self) -> Dict[str, float]:
        """
        Calculate comprehensive performance metrics.

        Returns:
            {
                'total_return': float,
                'annualized_return': float,
                'volatility': float,
                'sharpe_ratio': float,
                'sortino_ratio': float,
                'max_drawdown': float,
                'current_drawdown': float,
                'win_rate': float,
                'avg_win': float,
                'avg_loss': float,
                'profit_factor': float,
                'total_trades': int,
                'days_active': int
            }
        """
        portfolio_logger = PortfolioLogger(self.db_path)
        equity_curve = portfolio_logger.get_equity_curve()

        if len(equity_curve) < 2:
            return {}  # Not enough data

        # Returns series
        returns = equity_curve['daily_return'].dropna()

        # Total return
        initial = equity_curve.iloc[0]['total_value']
        final = equity_curve.iloc[-1]['total_value']
        total_return = (final - initial) / initial

        # Annualized return
        days = len(equity_curve)
        annualized_return = (1 + total_return) ** (252 / days) - 1

        # Volatility
        volatility = returns.std() * np.sqrt(252)

        # Sharpe ratio (assume 4% risk-free)
        rf_daily = 0.04 / 252
        excess_returns = returns - rf_daily
        sharpe_ratio = (excess_returns.mean() / excess_returns.std()) * np.sqrt(252) if excess_returns.std() > 0 else 0

        # Sortino ratio (downside deviation only)
        downside_returns = returns[returns < 0]
        downside_deviation = downside_returns.std() * np.sqrt(252) if len(downside_returns) > 0 else volatility
        sortino_ratio = (annualized_return - 0.04) / downside_deviation if downside_deviation > 0 else 0

        # Max drawdown
        cumulative = (1 + equity_curve['daily_return'].fillna(0)).cumprod()
        cummax = cumulative.cummax()
        drawdowns = (cumulative - cummax) / cummax
        max_drawdown = drawdowns.min()
        current_drawdown = drawdowns.iloc[-1]

        # Trade statistics
        with get_db_session(self.db_path) as session:
            trades = session.query(Trade).all()
            total_trades = len(trades)

            # Win/loss analysis (approximate from daily returns)
            winning_days = len(returns[returns > 0])
            losing_days = len(returns[returns < 0])
            win_rate = winning_days / len(returns) if len(returns) > 0 else 0
            avg_win = returns[returns > 0].mean() if winning_days > 0 else 0
            avg_loss = returns[returns < 0].mean() if losing_days > 0 else 0
            profit_factor = abs(avg_win / avg_loss) if avg_loss != 0 else 0

        return {
            'total_return': total_return,
            'annualized_return': annualized_return,
            'volatility': volatility,
            'sharpe_ratio': sharpe_ratio,
            'sortino_ratio': sortino_ratio,
            'max_drawdown': max_drawdown,
            'current_drawdown': current_drawdown,
            'win_rate': win_rate,
            'avg_win': avg_win,
            'avg_loss': avg_loss,
            'profit_factor': profit_factor,
            'total_trades': total_trades,
            'days_active': days
        }

    def calculate_rolling_sharpe(self, window: int = 30) -> pd.DataFrame:
        """
        Calculate rolling Sharpe ratio.

        Args:
            window: Rolling window in days

        Returns:
            DataFrame with timestamp and rolling_sharpe columns
        """
        portfolio_logger = PortfolioLogger(self.db_path)
        equity_curve = portfolio_logger.get_equity_curve()
        returns = equity_curve['daily_return'].fillna(0)

        rf_daily = 0.04 / 252
        excess_returns = returns - rf_daily

        rolling_sharpe = (
            excess_returns.rolling(window=window).mean() /
            excess_returns.rolling(window=window).std()
        ) * np.sqrt(252)

        return pd.DataFrame({
            'timestamp': equity_curve['timestamp'],
            'rolling_sharpe': rolling_sharpe
        })
```

### 6. Alert Monitor (`tracking/alerts/threshold_monitor.py`)

```python
class ThresholdMonitor:
    """
    Monitor performance metrics and trigger alerts on threshold breaches.
    """

    def __init__(self, db_path: str = "tracking/trading.db"):
        self.db_path = db_path
        self.thresholds = {
            'max_drawdown': -0.15,  # Alert if drawdown > -15%
            'daily_loss': -0.05,  # Alert if single day loss > -5%
            'volatility': 0.30,  # Alert if vol spikes > 30% annualized
            'concentration': 0.20  # Alert if single position > 20%
        }

    def check_all_thresholds(self) -> List[Alert]:
        """
        Check all thresholds and create alerts if breached.

        Returns list of alerts created (if any).
        """
        alerts = []

        # Check drawdown
        calc = MetricsCalculator(self.db_path)
        metrics = calc.calculate_all_metrics()

        if metrics.get('current_drawdown', 0) < self.thresholds['max_drawdown']:
            alert = self._create_alert(
                alert_type='drawdown',
                severity='critical',
                message=f"Portfolio drawdown {metrics['current_drawdown']:.1%} exceeds threshold {self.thresholds['max_drawdown']:.1%}"
            )
            alerts.append(alert)

        # Check daily loss
        portfolio_logger = PortfolioLogger(self.db_path)
        equity_curve = portfolio_logger.get_equity_curve()
        if len(equity_curve) > 0:
            last_return = equity_curve.iloc[-1]['daily_return']
            if last_return < self.thresholds['daily_loss']:
                alert = self._create_alert(
                    alert_type='daily_loss',
                    severity='warning',
                    message=f"Daily loss {last_return:.2%} exceeds threshold {self.thresholds['daily_loss']:.1%}"
                )
                alerts.append(alert)

        # Check volatility
        if metrics.get('volatility', 0) > self.thresholds['volatility']:
            alert = self._create_alert(
                alert_type='volatility',
                severity='warning',
                message=f"Volatility {metrics['volatility']:.1%} exceeds threshold {self.thresholds['volatility']:.1%}"
            )
            alerts.append(alert)

        # Check concentration
        with get_db_session(self.db_path) as session:
            holdings = session.query(Holding).all()
            if holdings:
                total_value = sum(h.market_value for h in holdings)
                for holding in holdings:
                    weight = holding.market_value / total_value
                    if weight > self.thresholds['concentration']:
                        alert = self._create_alert(
                            alert_type='concentration',
                            severity='warning',
                            message=f"{holding.symbol} concentration {weight:.1%} exceeds threshold {self.thresholds['concentration']:.1%}"
                        )
                        alerts.append(alert)

        return alerts

    def _create_alert(self, alert_type: str, severity: str, message: str) -> Alert:
        """Create and save an alert."""
        with get_db_session(self.db_path) as session:
            alert = Alert(
                timestamp=datetime.now(),
                alert_type=alert_type,
                severity=severity,
                message=message,
                acknowledged=False
            )
            session.add(alert)
            session.commit()
            return alert
```

```python
        total_value = latest['total_value'] if latest is not None else 25000
        for h in holdings:
            weight = h.market_value / total_value
            pnl_pct = (h.current_price - h.avg_cost) / h.avg_cost
            html += f"""
                <tr>
                    <td>{h.symbol}</td>
                    <td>{h.shares:.2f}</td>
                    <td>${h.avg_cost:.2f}</td>
                    <td>${h.current_price:.2f}</td>
                    <td>${h.market_value:,.2f}</td>
                    <td class="{'positive' if h.unrealized_pnl > 0 else 'negative'}">
                        ${h.unrealized_pnl:,.2f} ({pnl_pct:.1%})
                    </td>
                    <td>{weight:.1%}</td>
                </tr>
            """

        html += """
            </table>

            <h2>Recent Trades</h2>
            <table>
                <tr>
                    <th>Timestamp</th>
                    <th>Symbol</th>
                    <th>Side</th>
                    <th>Shares</th>
                    <th>Price</th>
                    <th>Notional</th>
                </tr>
        """

        for t in recent_trades:
            html += f"""
                <tr>
                    <td>{t.timestamp.strftime('%Y-%m-%d %H:%M')}</td>
                    <td>{t.symbol}</td>
                    <td class="{'positive' if t.side == 'buy' else 'negative'}">{t.side.upper()}</td>
                    <td>{t.shares:.2f}</td>
                    <td>${t.price:.2f}</td>
                    <td>${t.notional:,.2f}</td>
                </tr>
            """

        html += """
            </table>
        </body>
        </html>
        """

        # Save report
        Path(output_path).parent.mkdir(parents=True, exist_ok=True)
        with open(output_path, 'w') as f:
            f.write(html)

        return output_path
```
