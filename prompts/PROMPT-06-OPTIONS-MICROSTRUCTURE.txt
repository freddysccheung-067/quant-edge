## Required Background Knowledge

### Dealer Mechanics 101

**Options Market Makers (Dealers):**
- Sell options to customers (hedged dynamically)
- Must stay delta-neutral by trading the underlying (SPY)
- Their hedging creates predictable flows in the spot market

**Key Greeks:**
- **Delta (Δ)**: Sensitivity to price change. 1 contract = ±50 delta (per $1 move)
- **Gamma (Γ)**: Rate of change of delta. Dealer short gamma → must buy high, sell low (destabilizing)
- **Vanna**: Sensitivity to vol changes. Dealer short vanna → vol up = buy spot
- **Charm**: Delta decay with time. Dealer short charm → must buy into expiry

**The Trade:**
1. Aggregate all SPY options (calls & puts, all strikes, near-dated)
2. Calculate **net dealer positioning** (assume we're contra-side to customer flow)
3. When dealers are **short gamma** (negative Γ):
   - SPY up → dealers must sell SPY (dampen rally)
   - SPY down → dealers must buy SPY (dampen selloff)
   - **Result: Market is range-bound, choppy**
4. When dealers are **long gamma** (positive Γ):
   - SPY up → dealers sell into strength (provide liquidity)
   - SPY down → dealers buy dips (stabilize market)
   - **Result: Market is trending, directional**

**Our Signal:**
- Dealer short gamma < -$5B → Reduce equity exposure (choppy market coming)
- Dealer long gamma > +$2B → Increase equity exposure (trends incoming)

```python
    def cache_options_data(self, data: pd.DataFrame, symbol: str, date: datetime):
```

### 2. Greeks Calculator (`options/analytics/greeks.py`)

Implement **Black-Scholes-Merton model** for analytical Greeks.

```python
class GreeksCalculator:
    """
    Calculate all first and second-order Greeks analytically.

    Uses Black-Scholes-Merton for European-style options.
    SPY options are American but BSM is close enough for our purpose.
    """

    def __init__(self):
        pass

    def calculate_greeks(self,
                        spot: float,
                        strike: float,
                        time_to_expiry: float,  # Years
                        volatility: float,  # Implied vol (annualized)
                        risk_free_rate: float,
                        dividend_yield: float,
                        option_type: str) -> Dict[str, float]:
        """
        Calculate all Greeks for one option.

        Returns:
            {
                'delta': float,
                'gamma': float,
                'vega': float,
                'theta': float,
                'rho': float,
                'vanna': float,  # dDelta/dVol
                'charm': float,  # dDelta/dTime
                'vomma': float,  # dVega/dVol
                'speed': float   # dGamma/dSpot
            }
        """
        # Black-Scholes formulas:
        # Delta_call = N(d1)
        # Delta_put = N(d1) - 1
        # Gamma = N'(d1) / (S * σ * sqrt(T))
        # Vega = S * N'(d1) * sqrt(T)
        # Theta_call = ... (see formula)
        # Vanna = -N'(d1) * d2 / σ
        # Charm = -N'(d1) * [2*r*T - d2*σ*sqrt(T)] / (2*T*σ*sqrt(T))

    def _calculate_d1_d2(self, spot: float, strike: float,
                        time_to_expiry: float, volatility: float,
                        risk_free_rate: float, dividend_yield: float) -> Tuple[float, float]:
        """
        Calculate d1 and d2 from Black-Scholes formula.

        d1 = [ln(S/K) + (r - q + σ²/2)T] / (σ√T)
        d2 = d1 - σ√T
        """

    def _normal_cdf(self, x: float) -> float:
        """Standard normal CDF using scipy.stats.norm."""

    def _normal_pdf(self, x: float) -> float:
        """Standard normal PDF."""

    def batch_calculate_greeks(self, options_df: pd.DataFrame) -> pd.DataFrame:
        """
        Calculate Greeks for entire options chain efficiently.

        Vectorized implementation for speed.
        """
```

**Validation:**
- Delta: -1 to 0 for puts, 0 to 1 for calls
- Gamma: Always positive, peaks at-the-money
- Vega: Always positive
- Theta: Usually negative (time decay)
- Sum of call/put deltas at same strike ≈ 1 (put-call parity)

```python
class DealerPositioningAnalyzer:
    """
    Aggregate options chain to calculate net dealer positioning.

    Assumption: Customers are net buyers of options (hedging/speculation).
    Therefore, dealers are net sellers → we reverse sign.
    """

    def __init__(self, options_data: pd.DataFrame, spot_price: float):
        """
        Args:
            options_data: Full options chain with Greeks
            spot_price: Current SPY price
        """
        self.options_data = options_data
        self.spot_price = spot_price

    def calculate_net_dealer_exposure(self) -> Dict[str, float]:
        """
        Calculate aggregate dealer exposures.

        For each option contract:
        - Dealer delta = -100 * delta * open_interest * (1 if dealer sold else -1)
        - Dealer gamma = -100 * gamma * open_interest * (1 if dealer sold else -1)

        Assumptions:
        - Open interest = # contracts outstanding
        - 1 contract = 100 shares exposure
        - Dealers are contra-side (reverse sign)

        Returns:
            {
                'net_dealer_delta': float (shares of SPY exposure),
                'net_dealer_gamma': float (delta change per $1 SPY move),
                'net_dealer_vanna': float,
                'net_dealer_charm': float,
                'gamma_notional': float (gamma * spot² for dollar exposure),
                'gamma_flip_level': float (spot price where gamma = 0)
            }
        """

        # Customer flow assumption: more call buying above spot, put buying below
        # Use volume-weighted heuristic or fixed assumption

    def calculate_gamma_exposure_by_strike(self) -> pd.DataFrame:
        """
        Break down gamma exposure by strike level.

        Returns DataFrame:
            strike | call_gamma | put_gamma | net_gamma |
            call_oi | put_oi | distance_from_spot

        Useful for identifying "gamma walls" - strikes with huge OI.
        """

    def estimate_hedging_flow(self, spot_move: float) -> float:
        """
        Estimate dealer hedging flow for a given spot move.

        Args:
            spot_move: Hypothetical SPY price change (e.g., +1.0 = $1 up)

        Returns:
            Estimated shares dealers must buy/sell to stay delta-neutral.

        Formula:
            Flow = -dealer_gamma * spot_move

        Negative gamma → must buy on rallies (bad for momentum)
        Positive gamma → must sell on rallies (good for momentum)
        """

    def calculate_gamma_flip_level(self) -> float:
        """
        Find the SPY price level where dealer gamma flips from negative to positive.

        This is a critical level:
        - Above: Dealers are supportive (long gamma)
        - Below: Dealers are destabilizing (short gamma)

        Often called the "zero gamma strike" or "dealer pivot".
        """

    def historical_positioning_series(self,
                                     start_date: str,
                                     end_date: str) -> pd.DataFrame:
        """
        Calculate dealer positioning over time.

        Returns DataFrame:
            date | spot_price | dealer_gamma | dealer_delta |
            gamma_flip | regime (long/short)

        Requires fetching historical options chains (expensive!).
        Cache aggressively.
        """
```

### 6. Integration Script (`examples/run_options_analysis.py`)

```python
"""
Example: Daily options market microstructure analysis.

Run this every morning before market open to get:
1. Current dealer gamma positioning
2. Key strike levels to watch
3. Regime classification
4. Equity exposure recommendation
"""

from options.data.fetchers import OptionsDataFetcher
from options.analytics.greeks import GreeksCalculator
from options.analytics.dealer_positioning import DealerPositioningAnalyzer
from options.signals.gamma_regime import GammaRegimeSignal
from options.visualization.gamma_chart import plot_dealer_positioning_dashboard

def main():
    print("="*80)
    print("SPY OPTIONS MARKET MICROSTRUCTURE ANALYSIS")
    print("="*80)

    # Fetch data
    fetcher = OptionsDataFetcher(source="yfinance")
    print("\n[1/5] Fetching SPY options chain...")
    options_chain = fetcher.fetch_options_chain("SPY")
    spot_price = fetcher.get_spot_price("SPY")
    print(f"      SPY spot: ${spot_price:.2f}")
    print(f"      Options fetched: {len(options_chain)} contracts")

    # Calculate Greeks if not included
    if 'gamma' not in options_chain.columns:
        print("\n[2/5] Calculating Greeks...")
        greeks_calc = GreeksCalculator()
        options_chain = greeks_calc.batch_calculate_greeks(options_chain)
        print(f"      Greeks calculated for {len(options_chain)} contracts")
    else:
        print("\n[2/5] Greeks already in data, skipping calculation.")

    # Analyze dealer positioning
    print("\n[3/5] Analyzing dealer positioning...")
    analyzer = DealerPositioningAnalyzer(options_chain, spot_price)
    positioning = analyzer.calculate_net_dealer_exposure()

    print(f"\n      DEALER POSITIONING:")
    print(f"      Net Gamma:      ${positioning['gamma_notional']/1e9:.2f}B")
    print(f"      Net Delta:      {positioning['net_dealer_delta']/1e6:.1f}M shares")
    print(f"      Gamma Flip:     ${positioning['gamma_flip_level']:.2f}")

    # Generate signal
    print("\n[4/5] Generating trading signal...")
    signal_gen = GammaRegimeSignal()
    signal = signal_gen.generate_signal(positioning['gamma_notional'])

    print(f"\n      SIGNAL:")
    print(f"      Regime:         {signal['regime']}")
    print(f"      Equity Exposure: {signal['equity_exposure']:.0%}")
    print(f"      Confidence:     {signal['confidence']:.0%}")
    print(f"      Reason:         {signal['reason']}")

    # Visualize
    print("\n[5/5] Generating dashboard...")
    plot_dealer_positioning_dashboard(positioning, save_path="options/dashboard.png")
    print("      Dashboard saved: options/dashboard.png")

    print("\n" + "="*80)
    print("✅ Analysis complete!")
    print("="*80)

if __name__ == "__main__":
    main()
```
